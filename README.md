# Silicon Valley Ideological Universe · 硅谷思想宇宙

A bilingual knowledge graph of every ideology, lineage, conflict, and belief system
that shaped Silicon Valley from cybernetics (1948) to the AGI cathedral (2026).
Twenty-plus ideologies, twelve figures, five active AI ideological wars, five
long-form religion-of-tech essays — all interconnected, all written EN + 中文 by
hand, all explorable through a graph view, a timeline view, and per-node dossiers.

This is a research archive, not a blog. It treats each ideology as a feedback loop
with inputs (texts, thinkers, capital), outputs (products, institutions,
casualties), and an objective function. Read the graph; the genealogy reveals
itself.

## Stack

- Next.js 14 (App Router) · TypeScript · Tailwind CSS
- Cormorant Garamond (display), Manrope (body), Noto Serif/Sans SC (CJK), JetBrains Mono (technical)
- Bilingual content authored in TypeScript data files (`src/data/`), rendered through a React language context
- SVG knowledge-graph with curated 2D layout, hover/click interaction, edge typing (lineage · kin · conflict)

## Routes

- `/` — landing universe + cluster index
- `/graph` — full interactive knowledge graph
- `/timeline` — 1948 → present chronology
- `/figures` and `/figure/[slug]` — character profiles
- `/wars` and `/war/[slug]` — AI ideological wars
- `/essays` and `/essay/[slug]` — long-form essays
- `/ideology/[slug]` — per-ideology dossier (origins · doctrine · lineage · conflicts · trajectory)
